# Cloud Infrastructure: Containerization Fundamentals

Containerization provides lightweight, standalone executable packages containing everything needed to run an application.

## Key Container Technologies

- **Docker**: Provides container virtualization by isolating namespaces and control groups on the host Linux kernel.
- **Docker Compose**: Tool for defining and running multi-container Docker applications via YAML configurations.
- **OCI Standards**: Open Container Initiative specifications ensure image portability across diverse runtime environments.
