# KnowledgeOS Frontend Outline

1. Home: focus-next hero, current library signal, direct question entry.
2. Library: searchable resource collection with status-aware rows and resource-led imagery.
3. Resource Workspace: overview, reader/content, notes, progress, related evidence, and ask-this-resource action.
4. Ask: scope chooser, conversation history, grounded answer, and citations.
5. Focus: explainable next-resource queue.
6. Insights: library composition and completed or active learning signals.
7. Auth: a focused brand entry surface that keeps the existing form flow.
