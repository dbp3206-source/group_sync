# GroupSync UI Content Outline

1. Global shell: Home, My Schedule, Groups, Notifications, Profile.
2. Home command center: next activity, today, active groups, attention, recent updates.
3. My Schedule: week/day calendar, source legend, fast personal and recurring entry.
4. Group workspace: identity header, overview, availability, activity, and tournament context.
5. Availability: search criteria, strongest candidate, ranked alternatives, member coverage.
6. Study: next session, goals, location/material context, participants, organizer creation.
7. Badminton: lifecycle, registrations, check-in, courts, pairings, matches, scores, leaderboard, news.
8. Tournament: competition identity, roster, status controls, knockout bracket.
9. Supporting screens: notifications and profile with consistent hierarchy and states.
